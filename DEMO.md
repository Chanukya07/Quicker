# Demo Script

1. **Sign In:**
   - Navigate to `http://localhost:3000`.
   - Click "Sign in with Google".
   - Select a Google account (make sure it's added as a Test User in Google Cloud Console if the app is unverified).
2. **Consent Screen:**
   - Observe the OAuth consent screen requesting access to read emails.
   - Accept the permissions.
3. **Sync Now:**
   - On the dashboard, click the "Sync Now" button.
   - Look at the terminal or network tab to see the API route `/api/sync` proxying the request to n8n.
4. **Watch n8n Execution:**
   - Open `http://localhost:5678` in another tab.
   - Navigate to the `gmail-sync` workflow and click on "Executions" to watch it fetch emails, extract details via OpenRouter, and write to Firestore.
5. **Dashboard Populates:**
   - Return to the Next.js app tab.
   - Watch the dashboard automatically populate in real-time as Firestore documents are created.
   - You should see Total Spend, the Category Pie Chart, Top Merchants list, and Recurring Payments list.
6. **View Anomalies:**
   - Check the "Anomalies & Flags" section.
   - Read the natural language explanations generated by the secondary LLM (Claude) that explain *why* an item was flagged (e.g. "amount spike", "new merchant").
7. **Verify Original Source:**
   - Click the "View original email" link on any flagged item or recent transaction.
   - This will open a new tab directly to the original email in Gmail (`https://mail.google.com/mail/u/0/#inbox/<id>`), demonstrating full traceability without storing the email body.
8. **Disconnect & Cleanup:**
   - Click the "Disconnect Gmail" button in the header.
   - Verify that the dashboard resets and all Firestore data for the user is deleted (you can check Firebase Console to confirm).
